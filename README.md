# HumanOS Debugger

> The first AI engine that debugs human relationships like code

## Overview

HumanOS Debugger is a premium relationship conflict analysis platform that transforms emotional conflicts into actionable insights. Built with Apple-level design quality and user experience.

## Features

### Voice Input (NEW!)
- **30+ Languages Supported**: Speak in your native language
- **Real-time Transcription**: See your words appear as you speak
- **Visual Feedback**: Recording indicator and volume meter
- **Easy Toggle**: Switch between typing and speaking
- **Supported Languages**: English (US/UK), Spanish, French, German, Italian, Portuguese, Russian, Chinese, Japanese, Korean, Arabic, Hindi, Turkish, Polish, Dutch, Swedish, Danish, Finnish, Norwegian, Czech, Thai, Vietnamese, Indonesian, Ukrainian, Romanian, Greek, and more

### Core Modules

**1. Relationship Conflict Debugger**
- Analyzes emotional tones and intensities
- Identifies unmet emotional needs
- Maps escalation chains showing how conflicts spiral
- Pinpoints root misunderstandings

**2. Emotional Translation Layer**
- Detects communication dialects (direct, indirect, analytical, emotional, etc.)
- Identifies style mismatches causing friction
- Shows how each person interprets interactions differently
- Explains compatibility patterns

**3. Crisis Ripple Simulator**
- Simulates outcomes of different actions
- Shows trust degradation scores
- Predicts repair difficulty levels
- Visualizes timelines and probabilities

**4. Repair Playbook Generator**
- Step-by-step repair instructions
- Explains why each step matters
- Sets expected outcomes for actions
- Provides actionable strategies

- **Interactions**: Smooth animations and micro-interactions

### Design Principles
- Apple-inspired aesthetics with premium feel

- Gradient accents throughout
- Smooth transitions and hover states
- Responsive across all screen sizes

## Tech Stack

- **Frontend**: React 18 with TypeScript
- **Styling**: Tailwind CSS with custom utilities
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Database**: Supabase (configured but optional for demo)

## Getting Started

```bash

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
